In [ ]:
from matplotlib import pyplot as plt
layer = model.layers

cmaps = ['Reds', 'Greens', 'Blues']
bands = [0, 1, 2]
bnames = {0: 'Red', 1: 'Green', 2:'Blue'}
filters, biases = model.layers[0].get_weights()

for b in bands:
  fig, axs = plt.subplots(4, 8, figsize=(12, 12))
  allf = filters[:, :, b, :]
  meanf = allf.mean(axis=2)
  ex = plt.imshow(meanf, cmap=cmaps[b])
  for i in range(len(axs.flat)):
    f = filters[:, :, :, i]
    axs.flat[i].set_xticks([])
    axs.flat[i].set_yticks([])
    axs.flat[i].set_title('Node {0}'.format(i+1))
    im = axs.flat[i].imshow(f[:, :, b], cmap=cmaps[b])
  cbar_ax = fig.add_axes([1, 0.285, 0.09, 0.45])
  fig.colorbar(ex, ax=axs.ravel().tolist(), cax=cbar_ax)
  plt.subplots_adjust(hspace=-0.7)
  plt.suptitle('{} Band'.format(bnames[b]), y=0.8, fontsize=20)
  plt.show()
  print('')

images = [43, 47]
sp_names = ['Lodgepole Pine', 'White Spruce']
for j in range(len(images)):

  img = load_img(r'/content/drive/MyDrive/sub_test/openings/375/2/imgs/{}.tif'.format(images[j]), target_size=(120, 120))
  img = img_to_array(img)
  img = np.expand_dims(img, axis=0)
  feature_output = model_short.predict(img)

  fig, axs = plt.subplots(4, 8, figsize=(12, 12))

  allf = np.squeeze(feature_output, axis=0)
  meanf = allf.mean(axis=2)
  ex = plt.imshow(meanf, cmap='jet')

  for ftr in feature_output:
    for i in range(0, 32):
      axs.flat[i].imshow(ftr[:, :, i-1], cmap='jet')
      axs.flat[i].set_xticks([])
      axs.flat[i].set_yticks([])
      axs.flat[i].set_title('Node {0}'.format(i+1))

  plt.subplots_adjust(hspace=-0.7)
  cbar_ax = fig.add_axes([1, 0.285, 0.09, 0.45])
  fig.colorbar(ex, ax=axs.ravel().tolist(), cax=cbar_ax)
  plt.suptitle('{}'.format(sp_names[j]), y=0.8, fontsize=20)
  plt.show()
  print('')



















































































    

  • As we can see, some of the transformations result in pretty abstract representations of our data.
    • 

  • What's more, these images are the outputs from the first convolutional layer of our CNN.
    • 

  • Deeper layers produce even more abstract representations of our data.
    • 

  • As meaningless as these images may look to us, they reveal patterns to the CNN that allows it to classify the tree crown's species!
    • 

  • Look at Nodes 13, 26, 29 and 30 for example; these filters output high values for pixels that belong to lodgepole pine (displayed in red) and lower values for the pixels that belong to the white spruce crown.
    • 

  • We can see in Nodes 13, 26, 29 and 30 that the fractional lodgepole pine crown contained in the image of the white spruce crown is displayed in red.
    • 

  • We can also see that Node 7 is much brighter for the white spruce crown than it is for the lodgepole pine crown, whereas the opposite is true for Node 5.
